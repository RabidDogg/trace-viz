# Глоссарий

| Термин                  | Определение                                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Scopes Parsing**      | Процесс извлечения идентификаторов из массива строк, где данные представлены в формате пар ключ-значение, разделённых запятыми.                                                                                    |
| **Fallback Chain**      | Последовательность полей, проверяемых парсером до нахождения первого непустого значения. Поиск останавливается на первом совпадении.                                                                               |
| **Shifted Degradation** | Режим визуализации, при котором часть трейса содержит полную иерархическую информацию, а часть — только временные метки. Записи без идентификатора спана встраиваются в ближайший по времени родительский элемент. |
| **Flat Trace**          | Режим отображения, при котором идентификатор спана отсутствует у всех записей. Каждая запись размещается на отдельной строке в хронологическом порядке без иерархических отступов.                                 |
| **UNCATEGORIZED Logs**  | Записи, у которых отсутствуют все идентификаторы для группировки. Отображаются в виде табличного представления с фиксированным набором колонок и возможностью экспорта.                                            |
| **RawLogViewer**        | Компонент интерфейса, отображающий список некатегоризированных логов в стиле табличного вывода с кнопкой выгрузки в файл.                                                                                          |
| **Span Scope**          | Гарантия уникальности идентификатора спана в пределах одного трейса. Глобальная уникальность не требуется.                                                                                                         |
